# Cardiac Patient Monitoring System

ASP.NET Core Web API for a cardiac patient monitoring system.

## Technologies
C#, ASP.NET Core, EF Core, SQL Server, Identity, JWT, FluentValidation, xUnit, Moq, Swagger, Postman.

## Features
- Authentication and JWT protected routes
- Patient, Vital Signs, Medication, and Appointment CRUD
- Filtering and search
- DTOs and input validation
- Centralized exception handling
- EF Core migrations and seed data
- Automated unit tests

## API Documentation
Swagger and Postman are included for API testing and demonstration.

## Testing
Run all tests with:

`dotnet test`
