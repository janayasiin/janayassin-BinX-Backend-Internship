# Day 4 — ASP.NET Core Project Setup & Routing

In this lab, I created an ASP.NET Core Web API project and practiced building API endpoints using both Controllers and Minimal APIs. I learned how to configure the application using `Program.cs`, set up Swagger for API testing, and understand routing, route parameters, and HTTP GET requests.

Implemented endpoints using Controllers:
- GET `/api/products`
- GET `/api/products/{id}`

Implemented the same endpoints using Minimal APIs:
- GET `/products`
- GET `/products/{id}`

All endpoints were tested successfully using Swagger UI and Postman. This lab helped me understand the difference between Controller-based APIs and Minimal APIs, and how `Program.cs` is used to configure and run an ASP.NET Core application.
